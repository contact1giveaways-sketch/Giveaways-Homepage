Import Sheets → Supabase

Copiază tombolele și câștigătorii din Google Sheets în Supabase. Sheets-ul nu se modifică.

1Intră în contul Supabase

Emailul și parola contului creat în Supabase → Authentication.

2Citește datele din Sheets

Parola de admin din Apps Script (cea din Script Properties). E nevoie de ea ca să vină și ciornele.

3Verifică

Asta se va copia. Uită-te pe listă înainte de import.

4Importă
